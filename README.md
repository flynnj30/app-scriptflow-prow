# ScriptFlow Pro - Smart CRM & Notes Manager

A full-featured CRM with integrated notes management, appointment scheduling, task tracking, and smart workspace.

## 🚀 Features

### 📝 Notes Management
- Create, edit, rename, duplicate, delete, archive, restore, pin, favorite
- Auto-save with visual status (Saving... ✓ Saved)
- Undo/Redo with version history
- Rich text editing (Bold, Italic, Underline, Lists, Headings, Links, Quotes, Code Blocks)
- Markdown support with live preview
- Plain text mode toggle
- Templates (Meeting Notes, Sales Call, Follow-up, Daily Notes)
- PIN lock with auto-lock after inactivity (5 minutes)
- Export/Import (TXT, PDF, DOCX, HTML, Markdown, JSON)
- Word count, character count, reading time
- Last edited timestamp
- Folder organization (Work, Personal, Sales)
- Tag system with auto-complete
- 7 Color labels
- Search with highlight matching
- Sort by Recent, Name, Created, Pinned, Favorites
- Filter by Folder, Tag, Archive, Trash
- Drag & drop reordering
- Reminders with date/time

### 📅 CRM Features
- Monthly calendar view with appointment indicators
- Drag & drop appointments to reschedule
- Status tracking (Warm Call Booked, Meeting Booked, Held, Canceled, Rescheduled)
- Tag system (Qualified Warm Call, VIP, Negligent Warm Callback)
- Lead scoring (Hot/Warm/Cold)
- Quick add and smart import with NLP parsing
- List view with search and filters
- KPI dashboard (Today/Week/Month stats)
- Color-coded status badges
- Timezone support

### ✅ Task Management
- Create, complete, delete tasks
- Priority levels (Low/Medium/High)
- Due date tracking
- Link tasks to appointments
- Task filtering (All/Pending)
- Overdue and due-today indicators
- Task search
- KPI cards (Total, Pending, Completed, Overdue)

### 🚀 Smart Workspace
- Tabbed browser with navigation (Back, Forward, Reload, Home)
- Floating panels (Notepad, Script, Calculator, Timer, Clipboard)
- Quick copy library with templates (Email, SMS, Script, Response)
- Split screen mode
- Command palette (Ctrl+K)
- Session recovery with auto-save
- URL bookmarking
- Notes and script editor with auto-save
- Clipboard history
- Timer for call tracking
- Calculator

### 📊 Analytics & Reports
- Insights Dashboard with date range selector
- Appointment trend charts (Chart.js)
- Status distribution
- Lead score distribution (Hot/Warm/Cold)
- Tag distribution
- Goal progress tracking (Daily/Weekly/Monthly)
- Advanced Reports with conversion funnel
- 7-day trend analysis
- Performance metrics
- PDF export of reports

### 🔐 Security
- Firebase Authentication (Email/Password + Google)
- User profile management with avatar
- PIN lock for notes with auto-lock
- Encrypted local storage
- Session persistence
- Offline support with auto-sync
