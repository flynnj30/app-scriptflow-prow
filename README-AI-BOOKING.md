# ScriptFlow Pro — AI Booking Population

Transcript Studio now includes **AI Analyze & Populate** on the booking card.

Workflow:
1. Transcribe an audio file with Puter AI.
2. Review the captured transcript.
3. Click **AI Analyze & Populate**.
4. Puter AI maps the transcript into the booking format.
5. Review/edit the generated output.
6. Copy it or send it directly to Smart Import.

The AI prompt is constrained to transcript-supported facts. Missing or ambiguous information is returned as **Not specified**. Meeting notes follow:

**Attendees + Current Setup + Website Goal + What to Show + Interest/Attitude + Objection/Concern + Meeting Angle**

The existing deterministic extractor remains as a fallback and no other CRM/calendar features were intentionally modified.
