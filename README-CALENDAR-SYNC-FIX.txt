ScriptFlow Pro — Calendar Drag/Drop + Firestore Sync Fix

1. Calendar drag/drop now moves the appointment between its actual date buckets.
2. Month view supports dragging an appointment onto another calendar day.
3. Week view supports dragging an appointment to another day/time slot.
4. The local calendar is updated immediately and the change is queued for Firebase.
5. Pending changes are persisted in localStorage so an old Firestore snapshot cannot restore the old date.
6. Permission-denied Firebase writes no longer cause repeated console warnings or revert the local appointment.
7. FIRESTORE-RULES-APPOINTMENTS.txt contains the required rule to permit the signed-in user to write their own appointments. Merge it into your existing rules and deploy them.
8. ERR_BLOCKED_BY_CLIENT is generated by browser privacy/ad-blocking extensions and cannot be fixed by page JavaScript. Test with extensions disabled if it persists.
9. The Chrome extension message-channel error is external to the application; runtime-guards.js already suppresses only that exact external rejection.

Important: deploying the JavaScript alone cannot grant Firestore permissions. Deploy the appointment rule as well.
